# Third-party notices

The app bundles the following components. Their licence texts are in `public/licenses/` and are served with the app.

| Component | Use | Licence |
|---|---|---|
| [Inter](https://github.com/rsms/inter) | chart font (sans-serif), embedded into exports | SIL Open Font License 1.1 |
| [Source Serif 4](https://github.com/adobe-fonts/source-serif) | chart font (serif), embedded into exports | SIL Open Font License 1.1 |
| [JetBrains Mono](https://github.com/JetBrains/JetBrainsMono) | chart font (monospace), embedded into exports | SIL Open Font License 1.1 |
| [opentype.js](https://github.com/opentypejs/opentype.js) | reading font files for outlines and PDF | MIT |
| [Svelte](https://svelte.dev) | UI framework | MIT |

The fonts are used unmodified (WOFF files from the Fontsource packages). The SIL OFL permits embedding them in
documents and figures created with the app.
